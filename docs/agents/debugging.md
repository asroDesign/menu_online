# دیباگ و پایداری رابط کاربری

این سند سابقهٔ اصلاح‌های قابل‌تأیید در state، داده‌های asynchronous و lint را نگه می‌دارد. این اصلاح‌ها قابلیت تجاری تازه‌ای اضافه نمی‌کنند؛ رفتار فرم‌ها، فیلترها و داده‌های در حال بارگذاری را پایدار می‌کنند.

### قواعد lint

هیچ قاعده‌ای به‌صورت سراسری خاموش نشده است. effectهایی که برای دریافت داده، polling، یا همگام‌سازی draft فرم از مقدار بیرونی لازم‌اند، فقط در همان محل استثنای lint همراه با علت دارند. موارد قابل‌حل با تغییر ساختار، مانند reset فرم تیکت و نوشتن ref هنگام render، بدون استثنا اصلاح شدند.

### بررسی انجام‌شده

- ESLint کامل با Node همراه محیط: بدون خطا؛ ۱۸ هشدار باقی‌مانده (تصاویر `<img>` و directiveهای بی‌استفاده در فایل‌های خارج از این اصلاح).
- TypeScript با `tsc --noEmit --incremental false`: موفق.
- مجموعهٔ تست‌ها با `node --test --test-reporter=dot tests/*.test.cjs`: موفق.
- `git diff --check`: موفق.
- Build تولیدی و مرورگر محلی اجرا نشدند. اتصال localhost از محیط با `EPERM` رد شد؛ build پیش‌فرض نیز cache مشترک `.next` را تغییر می‌دهد. فایل `.env` خوانده یا چاپ نشد.
