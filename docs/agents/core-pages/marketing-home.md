# صفحه اصلی بازاریابی

مسیر `/`، فایل `src/app/page.tsx`، آخرین به‌روزرسانی ۲۰۲۶-۱۰-۲۴.

قرارداد کامل بازسازی، ترتیب بخش‌ها، منبع داده، CTAها، رفتار دامنه اختصاصی و محدودیت‌های محتوا در [راهنمای صفحه اصلی](../home-page.md) ثبت شده است. این سند ارجاع واحد است تا دو نسخه متفاوت از شرح صفحه نگهداری نشود.

نسخه فعلی شامل معرفی تجربه بیش از ۲۰ سال، نمایشگر تعاملی شش حوزه محصول، preview متحرک چهار صحنه‌ای برای منو/سفارش/رزرو/گزارش، جریان سفارش، تحلیل نمونه مواد اولیه، کاربردهای صنفی، مقایسه روش‌های کاری، راهنمای شش‌مرحله‌ای خرید، تعرفه پویا، FAQ کامل و محتوای منتشرشده CMS است. Preview برچسب نمونه دارد، مقادیر آن نمایشی است و با reduced-motion خودکار نمی‌چرخد. نام و مدت آزمایش از تنظیمات خوانده می‌شوند و خرید از checkout واقعی انجام می‌شود.
