# صفحه اصلی بازاریابی

مسیر `/`، فایل `src/app/page.tsx`، آخرین به‌روزرسانی ۲۰۲۶-۱۰-۲۵.

قرارداد کامل بازسازی، ترتیب بخش‌ها، منبع داده، CTAها، رفتار دامنه اختصاصی و محدودیت‌های محتوا در [راهنمای صفحه اصلی](../home-page.md) ثبت شده است. این سند ارجاع واحد است تا دو نسخه متفاوت از شرح صفحه نگهداری نشود.

نسخه فعلی شامل معرفی تجربه بیش از ۲۰ سال، نمایشگر تعاملی شش حوزه محصول، و preview هفت‌صحنه‌ای فروش زنده، ساخت غذا و قیمت‌گذاری، باشگاه مشتریان، حسابداری، منوی موبایل، رزرو و انبار هوشمند با دستور تهیه است. صحنه انبار هوشمند یک چرخهٔ عملیاتی نمونه را نشان می‌دهد: سفارش وارد می‌شود، رسپیِ مقدار مصرف بررسی می‌شود، موجودی مواد به‌روز می‌شود و نزدیک‌شدن ماده به نقطه سفارش هشدار می‌گیرد. مقدار مصرف و موجودی روی این صحنه mock هستند؛ آن‌ها از API یا دیتابیس کسب‌وکار خوانده نمی‌شوند. صحنه قیمت مستقل است: خمیر و سپس گوشت، پنیر و ادویه با ترتیب مشخص وارد ظرف می‌شوند؛ محاسبه هزینه/حاشیه سود، زوم قیمت، عکس یکسان محصول و بزرگ‌نمایی آن در قاب موبایل ادامه همان زنجیره است. دارایی پیتزا `public/images/marketing/pizza-four-seasons.webp` است. باشگاه، رویداد خرید، امتیاز، بازگشت مشتری و استفاده از جایزه را به‌صورت مسیر متحرک نشان می‌دهد. حسابداری مبلغ سفارش را میان کارتخوان و وجه نقد تقسیم و سه ردیف متوازن دفتر را با افکت ثبت می‌کند. نمودار فروش SVG رنگی، toast و اعداد متحرک، و پرواز پیتزا از موبایل به میز نیز در preview هستند. همهٔ عددها و رویدادهای preview نمونه‌اند و به API یا دادهٔ کسب‌وکار وصل نیستند؛ عنوان محیط آزمایشی این موضوع را روشن می‌کند. `prefers-reduced-motion` حرکت و چرخش خودکار را متوقف می‌کند. صفحه تعرفه از مؤلفه مشترک `pricing.tsx` و چهار دوره ۱/۳/۶/۱۲ماهه استفاده می‌کند؛ منبع تنظیم قیمت در [راهنمای قیمت‌گذاری](../../marketing-pricing.md) آمده است. شرح جزئیات، فایل‌ها و اعتبارسنجی در [راهنمای صفحه اصلی](../home-page.md) و گزارش‌های preview ثبت شده است. نام و مدت آزمایش از تنظیمات خوانده می‌شوند و خرید از checkout واقعی انجام می‌شود.

مسیر `/pos-system` یک صفحه بازاریابی جداگانه برای اپ ویندوز است. صفحه مسئله قطعی اینترنت، ۴ گام آماده‌سازی/ثبت محلی/چاپ/همگام‌سازی و امکانات/حدود نسخه جاری را نمایش می‌دهد. متن عمداً کامل‌بودن آفلاین همه ماژول‌ها یا تأیید بانکی کارتخوان را ادعا نمی‌کند. فایل‌ها: `src/app/pos-system/page.tsx` و `pos-system.css`.

فهرست `DemoMenuGallery` در صفحهٔ اصلی پس از راهنمای خرید و بلافاصله پیش از تعرفه‌ها نمایش داده می‌شود؛ بخش دمو از زیر hero برداشته شده و فقط یک‌بار رندر می‌شود. ترتیب کامل در [راهنمای صفحه اصلی](../home-page.md) آمده است.
