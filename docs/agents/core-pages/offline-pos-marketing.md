# صفحهٔ معرفی صندوق آفلاین ویندوز

مسیر عمومی: `/pos-system` — راهنمای صفحه: `src/app/pos-system/page.tsx` و `src/app/pos-system/pos-system.css`.

## هدف صفحه

توضیح روشن ارزش صندوق Windows برای کافه/رستورانی که با قطعی اینترنت روبه‌رو می‌شود. صفحه بازاریابی و راهنمای ظرفیت فعلی است، نه خود برنامهٔ صندوق و نه صفحهٔ تنظیم دستگاه. تمام محتوا باید با [محدودهٔ واقعی صندوق آفلاین](../modules/offline-pos.md) سازگار بماند.

## چیدمان و تعامل

1. `SiteHeader` مشترک و Hero دو ستونه: پیام ادامه ثبت فروش در قطعی، شرح کوتاه، لینک نصب‌کنندهٔ Windows موجود در GitHub Releases، شروع trial و سه نشانهٔ سریع (فروش محلی، تاریخچهٔ cacheشده، چاپ محلی).
2. Mock صندوق با منوی cache، سفارش نمونه، وضعیت ذخیره محلی، صف همگام‌سازی و پرینتر. همهٔ نام‌ها/قیمت‌ها دادهٔ نمایشی ثابت‌اند.
3. چهار کارت توانایی: ذخیرهٔ فروش محلی، تاریخچهٔ دریافت‌شده، چاپ محلی و پیگیری sync/conflict.
4. جریان چهارمرحله‌ای: اتصال و دریافت snapshot اولیه، ثبت فروش محلی، چاپ دستگاه و همگام‌سازی پس از برگشت اینترنت.
5. کارت حدود نسخه: همهٔ پنل آفلاین نیست؛ وضعیت سرور پس از sync مشخص می‌شود؛ تعارض بی‌صدا overwrite نمی‌شود؛ نصب/جفت‌سازی و snapshot اولیه اینترنت لازم دارد.
6. CTA درخواست نمایش/مشاوره و `SiteFooter` مشترک.

## رفتار و مقصد لینک‌ها

- دانلود، همان installer منتشرشده در route تنظیم صندوق است: `MenuPeak-Bridge-Setup-x64.exe`. این لینک را به installer پل چاپگر دیگری تغییر نده، مگر release رسمی برنامهٔ صندوق جایگزین شده باشد.
- CTA «شروع رایگان» به `/register?trial=demo`، «درخواست نمایش» به `/demo` و «درخواست مشاوره» به `/consultation` می‌رود.
- `/pos-system` باید در `src/app/sitemap.ts` باقی بماند و از هدر/فوتر قابل دسترسی باشد.
- صفحه Server Component است و metadata شامل عنوان، توضیح، canonical، OpenGraph و JSON-LD نوع `SoftwareApplication` برای Windows است.

## سازگاری دسترس‌پذیری و نمایش

CSS در محدوده کلاس `.mp-pos-page` قرار دارد تا ظاهر عمومی از پنل جدا بماند. عرض محتوای صفحه محدود است؛ Hero در عرض کمتر از 950px تک‌ستونه، کارت‌ها دو ستونه و در موبایل تک‌ستونه می‌شوند. Mock در موبایل بدون چرخش سه‌بعدی است. نشان‌ها با متن همراه‌اند و `prefers-reduced-motion` انیمیشن sync را حذف می‌کند.

## گزاره‌های ممنوع بدون پیاده‌سازی تازه

- این‌که تمام ماژول‌های پنل هنگام قطعی اینترنت کاملاً کار می‌کنند.
- این‌که ثبت رسید POS به‌تنهایی پرداخت را از بانک تأیید می‌کند یا SDK بانک/کارتخوان مستقل از اینترنت کار می‌کند.
- این‌که فروش محلی فوراً در دفتر مرکزی، موجودی مشترک یا همهٔ صندوق‌ها ثبت شده است.
- این‌که سوابق قدیمی‌تر از داده‌ای که پیش از قطعی در دستگاه cache/backfill شده همیشه در دسترس‌اند.
