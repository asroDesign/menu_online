# اپلیکیشن پیک

> مشخصات بازسازی عامل برای صفحه/جریان عمومی یا سیستمی.

- مسیر: `/courier`
- منبع فعلی: `src/app/courier/page.tsx + src/components/courier-app.tsx`
- هدف: صفحه موبایل پیک برای آنلاین شدن و دریافت/پیشبرد سفارش‌های تخصیص‌یافته.

## رابط و جریان

تأیید role courier؛ status حاضر/غایب؛ فهرست کارت‌های job با آدرس، تلفن، مبلغ و مراحل پذیرفتن/تحویل؛ اقدام تماس/نقشه؛ refresh؛ خروج.

## API و داده

GET /api/courier/orders؛ POST /api/courier/orders/:id actions؛ PATCH /api/courier/me؛ POST /api/auth/logout.

## قواعد بازسازی

سرور فقط jobهای courier جاری را برگرداند؛ transition assignment/state سرور validate؛ PII مشتری برای همان jobها؛ mobile-first.

برای schema دقیق و شرط‌های موجود، فایل‌های source و API بالا را بخوان. UI عمومی باید tenant-isolated، RTL و responsive باشد.

## مشخصات سطح پیاده‌سازی

### احراز هویت و فهرست کار

صفحه فقط نقش `courier` دارای feature ارسال را می‌پذیرد؛ سایر نقش‌ها به خانه مجاز هدایت یا پیام دسترسی می‌گیرند. `GET /api/courier/orders` فقط کارهای اختصاص‌یافته به همان پیک را می‌دهد. نمایش فهرست هر ۶ ثانیه در tab فعال تازه می‌شود؛ جابه‌جایی بین تب‌های فعال/انجام‌شده، وضعیت شیفت و logout جزو جریان اصلی است. سفارش جدید می‌تواند صدای کوتاه و vibration در صورت پشتیبانی مرورگر داشته باشد.

### جزئیات و اقدام‌ها

هر کارت شماره، مقصد/نشانی و نقشه، تلفن مشتری، اقلام و یادداشت، مبلغ و وضعیت پرداخت را دارد. پیک می‌تواند سفارش آماده را بردارد و پس از تحویل یکی از delivered/not_home/failed را ثبت کند؛ برای failed علت اجباری است. اگر سفارش هنوز پرداخت نشده باشد، ثبت روش دریافت نقدی/POS/کارت مطابق API ممکن است. هر اقدام busy شود، پس از پاسخ از سرور بازخوانی و در شکست قابل retry باشد. دکمه تماس باید `tel:` و نقشه فقط مختصات/نشانی همان سفارش را باز کند.

### ایمنی داده و پذیرش

سرور تنها سفارش‌های همین پیک را برگرداند و انتقال وضعیت/پول/assignment را validate کند. PII به کارهای تخصیص‌یافته محدود است. با پایان شیفت کار جدید نباید دریافت شود؛ پاسخ duplicate نباید دوبار پرداخت یا تحویل ثبت کند. صفحه برای موبایل، صفحه‌کلید و اینترنت ضعیف مناسب باشد؛ polling در tab مخفی متوقف/کم شود و کارت با خطای یک سفارش کل صفحه را از کار نیندازد.
