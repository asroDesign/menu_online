# صفحه معرفی صندوق آفلاین ویندوز

مسیر عمومی `/pos-system`، پیاده‌سازی در `src/app/pos-system/page.tsx`.

## هدف

این صفحه کاربرد MenuPeak Desktop را برای مدیر و صندوق‌دار توضیح می‌دهد: آماده‌سازی اولیه در زمان اتصال، ثبت سفارش روی رایانهٔ صندوق در قطعی، دسترسی به تاریخچه/جزئیات محلی، چاپ از پرینترهای همان دستگاه و همگام‌سازی پس از اتصال دوباره. صفحهٔ بازاریابی باید قابلیت عملیاتی را با حد و مرز واقعی توصیف کند؛ برای پرداخت کارتخوان خودکار یا همگام‌سازی آنی چند صندوق ادعا نسازد.

## ساختار

1. Hero شامل عنوان آفلاین، خلاصهٔ مسیر، CTA ساخت حساب و راهنمای تنظیمات صندوق.
2. تصویرسازی فاکتور نمونهٔ آفلاین: اقلام، جمع، تأیید ثبت محلی و اعلان sync؛ همه اعداد نمایشی‌اند.
3. گردش ۴ گام: دریافت اولیهٔ منو، ثبت سفارش، چاپ محلی، ارسال پس از اتصال.
4. کارت قابلیت‌ها: ذخیرهٔ محلی، تاریخچه/جزئیات آفلاین، چاپ محلی، دریافت نقدی یا ثبت رسید POS، همگام‌سازی، و اتصال کنترل‌شدهٔ دستگاه.
5. بخش پیش‌نیاز و محدودیت: اتصال اولیه برای نصب/دریافت منو لازم است؛ داده آفلاین هر دستگاه روی خودش نگه‌داری می‌شود؛ ثبت شماره پیگیری کارتخوان، پرداخت بانکی خودکار نیست و SDK/اتصال PSP برای انتقال مبلغ لازم است.
6. CTA نهایی برای شروع رایگان، راهنمای setup و مقایسه پلن‌ها.

## پیوندها و نمایه‌سازی

- بخش `MenuPeak Desktop · صندوق ویندوز` در صفحهٔ اصلی با CTA «معرفی و امکانات صندوق ویندوز» به `/pos-system` می‌رود؛ CTA راه‌اندازی جداگانه به `/dashboard/settings/offline-pos` متصل است.
- canonical و Open Graph از `getSiteUrl()` ساخته می‌شوند.
- مسیر `/pos-system` در `src/app/sitemap.ts` ثبت شده است.
- Header و Footer بازاریابی مشترک استفاده می‌شوند؛ layout با Tailwind/DaisyUI واکنش‌گراست و کامپوننت/دیتابیس/مهاجرت جدا ندارد.

## نگهداری و آزمون

تغییرهای بازاریابی این صفحه را اینجا و در `docs/updates/2026-10-29-desktop-landing-and-visible-inventory-preview.md` ثبت کن. صحت build و لینک را پس از هر تغییر بازبینی کن؛ لینک‌های setup و checkout را با حساب واقعی/پرداخت واقعی آزمایش نکن.
