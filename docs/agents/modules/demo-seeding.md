# ماژول seed داده‌های نمایشی


## رفع خطای seed کاتالوگ ناقص — ۲۰۲۶-۱۰-۱۹
- علت: seed اولیه با وجود حساب نمایشی قبلی از ساخت کسب‌وکار/محصولات خارج می‌شد؛ seed تکمیلی فرض می‌کرد تمام نام‌های فعلی `CATALOG` وجود دارند و `P(name).id` برای محصول قدیمی/مفقود به TypeError می‌رسید.
- پیش از ساخت داده‌های وابسته، دسته‌های کاتالوگ غایب برای کسب‌وکار موجود اضافه می‌شوند؛ سپس محصولات مفقود از همان `CATALOG` با دسته صحیح و ویژگی‌های پایه وارد می‌شوند. محصولات موجود تغییر نمی‌کنند. جست‌وجوی نام `P` اکنون به‌جای خطای مبهم، invariant شامل نام محصول و شناسه کسب‌وکار را گزارش می‌کند.
- از اطلاعات نمایشی خارج از بستر seed استفاده نمی‌شود؛ اجرای seed نیازمند دیتابیس عملیاتی نیست و در این تغییر اجرا نشده است.
