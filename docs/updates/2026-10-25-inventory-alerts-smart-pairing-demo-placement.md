# هشدارهای انبار، پیشنهاد هوشمند غذا/نوشیدنی و جابه‌جایی دموها — ۲۰۲۶-۱۰-۲۵

## چه چیزی اضافه شد

- در هدر پنل رستوران، مرکز هشدار انبار با شمارنده و فهرست قابل‌اسکرول اضافه شد. هشدار موجودی صفر/منفی، موجودی مثبت در حد یا پایین‌تر از حداقل، انقضای گذشته و انقضای تا هفت روز آینده را نشان می‌دهد. تاریخ‌ها شمسی‌اند و تشخیص روز بر اساس تقویم تهران است.
- `GET /api/r/inventory-alerts` با نشست کاربر، entitlement انبار و `businessId` جاری، فقط اقلام فعال همان فروشگاه را می‌خواند؛ حداکثر ۲۵۰ قلم کاندید می‌گیرد و cache پاسخ را می‌بندد. Toast آغاز وضعیت تازه در همان نشست یک‌بار نمایش داده می‌شود؛ هشدار بحرانی از رنگ خطا و هشدار معمول از رنگ زرد استفاده می‌کند. پنل هر دو دقیقه و فقط در تب قابل‌مشاهده تازه می‌شود. schema و migration تغییر نکرده‌اند.
- پیشنهاد مکمل منوی مشتری هوشمندتر شد: پیشنهادهای دستی اولویت بالاتر دارند، سپس همراهی‌های پرتکرار از سفارش‌های گذشته می‌آیند و الگوریتم دسته‌بندی غذا/نوشیدنی سمت خالی سبد را پیشنهاد می‌کند. مشتری برچسب «نوشیدنی مناسب این غذا» یا «غذای همراه این نوشیدنی» را می‌بیند. تشخیص بر پایه نام محصول و دسته‌بندی است، LLM/AI ادعا نمی‌شود؛ پیشنهاد خودکار از تنظیم فعلی `crossSellAuto` پیروی می‌کند.
- `DemoMenuGallery` از بلافاصله پس از hero به بخش بعد از راهنمای خرید و درست پیش از تعرفه‌ها منتقل شد؛ فقط یک‌بار رندر می‌شود. مقصدها و محتوا تغییر نکردند.
- همهٔ تغییرهای این کار در `docs/agents/modules/inventory.md`, `docs/agents/modules/cross-sell.md`, `docs/agents/module-capabilities.md`, `docs/agents/README.md` و راهنمای صفحه اصلی ثبت شده‌اند.

## آزمون‌ها و محدودیت‌ها

- آزمون‌های جدید `tests/inventory-alerts.test.cjs` و `tests/menu-recommendations.test.cjs`: ۴ تست موفق؛ timezone/مرز هفت روز، اتمام و کمبود، دسته‌بندی فارسی و جفت‌سازی غذا/نوشیدنی را پوشش می‌دهند.
- تست جایگاه دمو در `tests/demo-menus.test.cjs` با ترتیب جدید صفحه هم‌راستا شد.
- `npm run typecheck -- --incremental false`, ESLint فایل‌های هدف و `git diff --check` موفق شدند.
- مجموعه کامل Node test: ۱۹۶ تست، ۱۸۶ موفق، ۳ شکست، ۷ مورد skip. سه شکست مربوط به تست‌های قبلی جریان دموی مشترک‌اند: ورود/checkout/رزرو دمو، whitelist قالب‌ها و رزرو، و متن حالت read-only دمو/گارسون؛ به مسیرهای این تغییر مربوط نیستند.
- `npm run build` با Node سیستمی `18.17.1` اجرا نمی‌شود چون Next.js حداقل `20.9.0` می‌خواهد. با runtime بسته‌بندی‌شدهٔ Node `24.22.1` ساخت شروع شد؛ در بررسی بعدی Next اعلام کرد یک build دیگر هنوز در حال اجراست. خروجی نهایی آن build در این گزارش تأیید نشده و باید پس از آزادشدن lock دوباره بررسی شود.
- دیتابیس، مرورگر واقعی، اعلان native مرورگر، و query عملیاتی روی tenant واقعی آزمایش نشده‌اند. API و helperها با typecheck و تست‌های واحد بررسی شدند.
