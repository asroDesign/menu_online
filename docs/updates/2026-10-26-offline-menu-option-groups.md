# مدیریت آفلاین گزینه‌های محصول — ۲۰۲۶-۱۰-۲۶

## مسئله

کاتالوگ POS آفلاین از قبل گروه‌های گزینهٔ محصول را برای قیمت‌گذاری سفارش می‌خواند، اما صفحهٔ «منوی محلی» فقط نام، شرح، قیمت و موجودبودن را ویرایش می‌کرد. مدیر نمی‌توانست در زمان قطعی، افزودنی مثل اندازه/نوع نان را برای محصول موجود بسازد یا همراه محصول تازه وارد کند.

## رفتار اضافه‌شده

- فرم ساخت/ویرایش محصول در Windows یک ویرایشگر ساختاریافتهٔ گروه/گزینه دارد. هر محصول تا ۱۲ گروه، هر گروه تا ۲۰ گزینه، حداقل/حداکثر انتخاب، اجباری/فعال بودن گروه و نام/فعال بودن/تغییر قیمت صحیح گزینه (مثبت یا منفی) می‌گیرد. ویرایشگر برای موبایل/پنجرهٔ باریک نیز grid واکنش‌گرا دارد.
- ایجاد محصول تازه، گروه‌های گزینه را در `create_product` رمز‌شده و idempotent می‌فرستد. ویرایش محصول موجود، `modifierGroups` را در patch می‌فرستد و pending overlay در همان صفحه گروه‌ها را نشان می‌دهد.
- UI، Rust و سرور قواعد حد تعداد، شناسهٔ یکتا، قیمت و امکان انتخاب را کنترل می‌کنند. سرور از helper مشترک `normalizeProductOptionGroups` استفاده می‌کند. در ویرایش، `modifierGroups` snapshot پایه با وضعیت زیر قفل محصول مقایسه می‌شود؛ تغییر هم‌زمان conflict می‌شود و بازنویسی خاموش رخ نمی‌دهد.
- محصول/گروه تازه تا تأیید سرور و دریافت catalog/snapshot تازه قابل سفارش نیست. فروش با snapshot صندوق همچنان قیمت option را محلی محاسبه می‌کند و هنگام sync همان انتخاب را با گروه‌های موجود در snapshot immutable سرور دوباره اعتبارسنجی می‌کند.

## فایل‌ها

- `windows-bridge/ui/index.html`, `style.css`, `pos.js`: ویرایشگر گروه‌ها و گزینه‌های محصول در فرم منوی محلی.
- `windows-bridge/offline-core/src/lib.rs`: اعتبارسنجی محلی، canonicalization و ثبت تغییر در outbox PINدار؛ آزمون Rust برای محدوده، ID یکتا و حد انتخاب.
- `src/lib/offline-dashboard.ts`: اعتبارسنجی API با helper مشترک، پذیرش `modifierGroups` در ساخت/ویرایش و تشخیص تعارض با نسخهٔ server.
- `tests/offline-modifier-groups.test.cjs`: آزمون helper واقعی قرارداد محصول برای قیمت کاهشی، شناسه تکراری و حد ناممکن.
- راهنمای صندوق آفلاین، نقشهٔ کلاینت آفلاین، نقشهٔ API، کاتالوگ ماژول‌ها، راهنمای شروع agent و `IMPLEMENTATION_STATUS.md`.

## سازگاری و بررسی

تغییر schema دیتابیس لازم نیست. `modifierGroups` از قبل در snapshot منو و منطق POS وجود داشت؛ تغییر جدید فقط اجازهٔ ایجاد/ویرایش کنترل‌شده را اضافه می‌کند. `node --test tests/offline-modifier-groups.test.cjs` با ۲ آزمون موفق شد؛ TypeScript typecheck، ESLint فایل‌های تغییرکرده، `node --check windows-bridge/ui/pos.js` و `git diff --check` هم موفق شدند. npm هشدار داد که npm 11.3.0 با Node 18.17.1 پشتیبانی رسمی ندارد، ولی دستورات خارج از خطا تمام شدند. `cargo` و `rustc` در محیط وجود ندارند؛ بنابراین Rust unit test و build واقعی برنامهٔ Tauri اجرا نشدند. PostgreSQL و نصب Windows هم آزمایش نشده‌اند.

این vertical slice تمام ویرایشگر محصول را آفلاین نمی‌کند: رسانه، recipe، تحلیل هزینه، تنوع قیمت، حذف و بایگانی هنوز نیازمند توسعه‌اند. این پروژه همچنان به هدف کامل آفلاین‌سازی کل پنل ادامه دارد.
