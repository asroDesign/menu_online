# جابه‌جایی سکشن معرفی امکانات صفحهٔ اصلی

تاریخ: ۲۰۲۶-۱۰-۳۰

سکشن «از روی میز تا پشت صحنه» در صفحهٔ اصلی (`/`) بلافاصله بعد از معرفی `MenuPeak Desktop · صندوق ویندوز` قرار گرفت. حالا بازدیدکننده ابتدا جریان هماهنگی یک سفارش و نسخهٔ صندوق ویندوز را می‌بیند و سپس با شش حوزهٔ امکانات تعاملی محصول آشنا می‌شود.

محتوای سکشن، `ProductTour`، شناسهٔ `features`، استایل‌ها، مقصد لینک‌ها و منطق صفحه دست‌نخورده ماندند؛ فقط جای قرارگیری در `src/app/page.tsx` تغییر کرد. ترتیب فعلی در `docs/agents/home-page.md` ثبت شده است. API، پایگاه داده، migration و رفتار خرید تغییر نکردند.

اعتبارسنجی: ESLint هدفمند `src/app/page.tsx`، TypeScript، `git diff --check` و بررسی ترتیب سکشن‌ها در Chrome محلی.
