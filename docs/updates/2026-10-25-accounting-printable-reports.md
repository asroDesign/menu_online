# چاپ تراز آزمایشی و دفتر حساب — ۲۰۲۶-۱۰-۲۵

## تغییرات انجام‌شده
- تراز آزمایشی برای سطوح کل، معین و تفصیلی دو خروجی چاپی دارد: «۴ ستونی» و «۲ ستونی».
- خروجی ۴ ستونی گردش بدهکار/بستانکار و مانده بدهکار/بستانکار را چاپ می‌کند و در A4 افقی می‌آید.
- خروجی ۲ ستونی کد/نام حساب و مانده بدهکار/بستانکار را چاپ می‌کند و در A4 عمودی می‌آید؛ گردش دوره را در این قالب وارد نمی‌کند.
- هر دو خروجی عنوان مجموعه، سربرگ حسابداری، دوره و سال مالی، واحد تومان، جمع ستون‌ها، توضیح قالب، تاریخ چاپ و محل امضا دارند.
- در دفتر حساب، بعد از انتخاب حساب کل، معین یا تفصیلی، «چاپ صورت حساب» نمایش داده می‌شود. API سقف ۳۰۰۰ خط دارد؛ در رسیدن به سقف هشدار نمایش داده و چاپ غیرفعال می‌شود تا گزارش ناقص چاپ نشود و کاربر بازه را محدود کند. خروجی شامل سربرگ کسب‌وکار، سطح و نام حساب، بازه، مانده ابتدا، گردش‌های سندی، جمع بدهکار/بستانکار، مانده پایان و محل امضا است.
- چاپ در پنجره جدا با ابعاد A4 اجرا می‌شود تا فقط گزارش انتخاب‌شده چاپ شود و اجزای پنل وارد برگه نشوند. داده‌ها از همان درخواست‌های گزارش جاری و همان فیلتر بازه استفاده می‌کنند.

## فایل‌ها و منطق
- `src/modules/accounting.tsx` و `src/lib/accounting.ts`: واکشی نام کسب‌وکار برای سربرگ، دکمه‌های چاپ دو قالب تراز، دکمه چاپ صورت حساب، هشدار سقف ۳۰۰۰ خط و ساخت سند HTML امن با escape کردن متن.
- `docs/agents/modules/accounting.md`, `docs/agents/module-capabilities.md`, `docs/agents/README.md`, `IMPLEMENTATION_STATUS.md`: قرارداد قابلیت و راهنمای عامل.
- migration یا تغییر API لازم نبود.

## بررسی
- `npm run typecheck`: موفق.
- `npx eslint src/modules/accounting.tsx`: موفق.
- در Chrome، دکمه‌های چاپ دو قالب تراز دیده شدند؛ در دفتر کل پس از انتخاب حساب، دکمه چاپ و خطوط گردش نشان داده شد. چاپ فیزیکی انجام ندادم و پنجره چاپ واقعی را باز نکردم.
- تست خودکار اجرا نشد.
