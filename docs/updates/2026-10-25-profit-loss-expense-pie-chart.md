# نمودار دایره‌ای نوع هزینه‌ها در سود و زیان — ۲۰۲۶-۱۰-۲۵

## رفتار اضافه‌شده

- در `/dashboard/profit-loss` کارت «ترکیب هزینه‌ها» اکنون سهم هر دسته از هزینه‌های عملیاتی بازهٔ انتخاب‌شده را در نمودار دایره‌ای SVG نشان می‌دهد.
- legend هم‌زمان مبلغ فشرده و سهم درصدی هر دسته را نشان می‌دهد؛ جمع کل هزینه در پایین کارت آمده و فهرست دسته‌ها در ارتفاع محدود اسکرول می‌شود.
- رنگ اولین بخش از رنگ سازمانی جاری می‌آید و بخش‌های بعدی رنگ‌های متمایز دارند. هیچ کتابخانهٔ نمودار جدیدی اضافه نشده است.
- `GET /api/r/report_pnl` برای ردیف‌های هزینهٔ حساب‌محور، نام حساب معین هزینه را در `expenseBreakdown` استفاده می‌کند. ردیف‌های تاریخی بدون حساب همچنان با `category` ذخیره‌شده گروه‌بندی می‌شوند و اگر آن هم خالی باشد در «سایر» قرار می‌گیرند.
- نمودار از همان فیلتر ۷/۱۴/۳۰ روز گزارش پیروی می‌کند؛ مقادیر صفر و منفی وارد pie نمی‌شوند و در نبود هزینه پیام خالی نمایش داده می‌شود.

## اعتبارسنجی

`npx tsc --noEmit --incremental false` و ESLint هدفمند `finance.tsx` و `registry-b.ts` موفق شدند؛ `git diff --check` هم موفق بود. npm هشدار می‌دهد npm 11 با Node 18.17.1 سازگاری کامل ندارد، ولی هر سه فرمان با کد خروج صفر تمام شدند. مرورگر و دیتابیس واقعی اجرا نشدند؛ route گزارش موجود است و migration جدیدی لازم نیست.
