# روشن‌سازی پیش‌نمایش حسابداری صفحهٔ اصلی

تاریخ: ۲۰۲۶-۱۰-۳۰

## درخواست

در سکشن «پیش‌نمایش امکانات MenuPeak»، زمینهٔ کارت حسابداری روشن شود و اجزای انیمیشن که کوچک بودند بزرگ‌تر و نزدیک‌تر به اندازهٔ نمونه شوند.

## پیاده‌سازی

- پنل حسابداری و سربرگ آن از رنگ‌های سرمه‌ای به سطح سفید/آبی بسیار روشن تغییر کردند؛ متن، کادرها و خط‌های اتصال برای کنتراست روشن بازتنظیم شدند.
- ناحیهٔ اتصال بزرگ‌تر شد. شش ورودی صندوق، منوی QR، باشگاه، انبار، بانک و دفتر حساب حالا آیکن ۴۸ پیکسلی، برچسب ۱۰ پیکسلی و زیرعنوان ۹ پیکسلی دارند.
- دفتر مرکزی اکنون کارت روشن با رقم کل ۱۶ پیکسلی و ردیف‌های حداقل ۳۲ پیکسلی/متن ۹ پیکسلی است. برای خالی نماندن یک سمت کارت، دفتر به اندازهٔ محتوایش در وسط شبکه قرار می‌گیرد. حالت متوازن سند همچنان با تأکید سبز متحرک می‌شود.
- در چیدمان موبایل، آیکن‌ها، متن و ردیف‌های سند نیز افزایش یافته‌اند؛ شش ماژول به کارت‌های روشن دوستونه و دفتر مرکزی به بخش تمام‌عرض تبدیل می‌شود.
- هیچ داده، endpoint، محاسبه یا رفتار واقعی حسابداری تغییر نکرده است؛ ارقام همچنان نمونهٔ نمایشی هستند.

## فایل‌ها

- `src/components/marketing/homepage-showcase.tsx`: افزایش اندازهٔ آیکن‌های شش گره.
- `src/components/marketing/home.css`: زمینهٔ روشن و اندازه/فاصله‌های جدید دسکتاپ و موبایل.
- `docs/agents/home-page.md` و `docs/agents/core-pages/marketing-home.md`: قرارداد فعلی نمایش.
- `IMPLEMENTATION_STATUS.md`: ثبت تغییر در ابتدای سابقه.

## اعتبارسنجی

- بررسی بصری در Chrome روی `http://localhost:3000/` و تب «حسابداری» انجام شد؛ زمینهٔ روشن، سند سفید و گره‌های بزرگ‌تر در صفحه دیده شدند.
- بررسی بصری در Chrome دسکتاپ روی `http://localhost:3000/` و تب «حسابداری» تأیید کرد که زمینه روشن، کارت دفتر سفید و اجزای بزرگ‌تر رندر می‌شوند. CSS موبایل برای کارت‌های دوستونه و دفتر تمام‌عرض اصلاح شد، اما viewport موبایل جداگانه در Chrome شبیه‌سازی نشد.
- `npx eslint src/components/marketing/homepage-showcase.tsx`، `npm run typecheck -- --incremental false` و `git diff --check` موفق شدند. npm برای Node ۱۸ هشدار سازگاری نسخه داد؛ هر سه دستور با موفقیت پایان یافتند. Build production اجرا نشد.
