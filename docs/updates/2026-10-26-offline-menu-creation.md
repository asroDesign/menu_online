# ساخت پایهٔ محصول و دسته‌بندی منو در Windows آفلاین

## دامنه

افزودن محصولات و دسته‌بندی‌ها بخشی از عملیات روزانهٔ رستوران است. این برش امکان ثبت پایهٔ آن‌ها در قطعی اینترنت را می‌دهد و تا زمان تأیید سرور، شناسه یا موجودی ساختگی وارد catalog فروش نمی‌کند.

## رفتار پیاده‌شده

- تب «منوی محلی» دکمهٔ ایجاد محصول و دسته‌بندی دارد. هر دو با PIN مدیر محلی فعال می‌شوند و فقط روی snapshot معتبر منو عمل می‌کنند.
- محصول شامل نام، توضیح، قیمت عددصحیح مثبت و دستهٔ فعالِ موجود در snapshot (اختیاری) است. قیمت صفر و بیش از ۱۰۰٬۰۰۰٬۰۰۰ تومان رد می‌شود.
- دسته شامل نام، توضیح، ترتیب و وضعیت فعال است. چون شناسهٔ سرور پیش از sync موجود نیست، محصول آفلاین به دستهٔ تازهٔ صف‌شده وصل نمی‌شود.
- SQLite فرمان را با UUID، tenant و snapshot پایه در صف DPAPI رمز‌شده ثبت می‌کند. UI نام قلم ایجادشده را هنگام ثبت اعلام می‌کند و وضعیت فرمان را نشان می‌دهد؛ قلم تا sync موفق و snapshot تازه برای سفارش انتخاب‌پذیر نمی‌شود.
- سرور payload را strict parse می‌کند، terminal و tenant فعال را قفل/بازبینی می‌کند، snapshot منو را کنترل می‌کند، برای دستهٔ محصول عضویت در snapshot و فعال‌بودن جاری را می‌سنجد و درج ردیف جدید همراه ledger idempotency را در یک transaction انجام می‌دهد. retry همان UUID پاسخ ثبت‌شده را برمی‌گرداند و محصول/دستهٔ دوم نمی‌سازد.
- migration `0070_offline_menu_creation.sql` ترکیب‌های create را به allowlist دیتابیس اضافه می‌کند. down migration اگر سابقهٔ این فرمان‌ها وجود داشته باشد rollback را متوقف می‌کند.

## خارج از این برش

ساخت محصول هنوز تصویر/ویدیو، افزودنی‌ها، تنوع قیمت، دستور تهیه، برچسب‌ها و مدل سه‌بعدی ندارد. حذف و بایگانی محصول/دسته، والد/زیر‌دسته و ساخت محصول با شناسهٔ دستهٔ هنوز sync‌نشده نیز آفلاین نیستند. بعد از اتصال، باید پاسخ فرمان و snapshot تازه دریافت شود تا قلم رسمی برای POS در دسترس قرار بگیرد.

## اعتبارسنجی

`npx tsc --noEmit --incremental false` موفق شد. بررسی syntax جاوااسکریپت، ESLint هدفمند و `git diff --check` نیز اجرا می‌شوند. به دیتابیس متصل نمی‌شویم و migration یا تست integration اجرا نمی‌کنیم. `cargo`, `rustc` و `rustfmt` در محیط موجود نیستند، پس compile واقعی Windows/Tauri را نمی‌توان تأیید کرد.
