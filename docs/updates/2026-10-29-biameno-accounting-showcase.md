# بازطراحی پیش‌نمایش حسابداری صفحهٔ اصلی با الهام از بیامنو

تاریخ: ۲۰۲۶-۱۰-۲۹

## هدف

تب حسابداری در سکشن «پیش‌نمایش امکانات MenuPeak» باید پیام اتصال عملیات روزانه به حسابداری را روشن‌تر و از نظر بصری به سکشن حسابداری بیامنو نزدیک کند. مرجع در Chrome بررسی شد: [نرم‌افزار حسابداری بیامنو](https://www.biameno.ir/accounting-software/).

## پیاده‌سازی

- کارت قبلیِ صرفاً دریافت مبلغ و ثبت سه ردیف سند به یک hero فشردهٔ معرفی محصول تبدیل شد: متن سمت راست، نمودار اتصال سیستم‌ها سمت چپ، با تم سرمه‌ای، خطوط شبکه‌ای، گره‌های روشن و انیمیشن جریان.
- پیام معرفی «حساب‌هایتان خودشان ثبت می‌شوند» و متن نزدیک به نمونهٔ بیامنو به‌کار رفت: «صندوق، منوی QR، باشگاه مشتریان و انبار حالا مستقیم به حسابداری MenuPeak وصل‌اند. هر فروش، هر تخفیف و هر کالایی که از انبار می‌رود، خودکار سند می‌شود. شما فقط نگاه می‌کنید: امروز چقدر سود کردید؟» کپی برای نام محصول MenuPeak تنظیم شده است؛ از لوگو و دارایی اختصاصی سایت مرجع استفاده نشده است.
- نمودار شش ماژول صندوق، منوی QR، باشگاه، انبار، بانک/چک و دفتر حساب را به سند مرکزی وصل می‌کند. سند فاکتور نمونهٔ ۶۳۵٬۰۰۰ تومانی را با ۴۵۰٬۰۰۰ تومان کارتخوان و ۱۸۵٬۰۰۰ تومان نقد، و درآمد ۶۳۵٬۰۰۰ تومان نشان می‌دهد؛ بدهکار و بستانکار برابرند.
- چهار فاز تعاملی قبلی نگه داشته شد: اتصال، مسیریابی دریافت، ظاهرشدن ردیف‌ها و سند متوازن. برای کاهش حرکت، فاز پایانی نمایش داده می‌شود.
- در mobile، متن بالای گرافیک می‌آید، گره‌ها به کارت‌های دوستونه تغییر می‌کنند و دفتر نمونه تمام عرض می‌شود؛ در ۳۹۰ پیکسل و کمتر، نکته‌های معرفی تک‌ستونه هستند.

## محدودیت و دامنه

تمام ارقام و اتصال‌های نشان‌داده‌شده دادهٔ ثابت نمونهٔ بازاریابی‌اند و از فروشگاه یا API خوانده نمی‌شوند. این تغییر فقط به `src/components/marketing/homepage-showcase.tsx` و `src/components/marketing/home.css` مربوط است. منطق حسابداری پنل، تسویهٔ واقعی، API، دادهٔ عملیاتی، دیتابیس و migration تغییر نکردند. پشتیبانی چندشعبه/مود آفلاین/مالیات، که در صفحهٔ مرجع هم معرفی شده‌اند، در این preview ادعا نشده‌اند.

## مستندات مرتبط

- قرارداد صفحهٔ اصلی: `docs/agents/home-page.md`
- مسیر بازاریابی صفحهٔ اصلی: `docs/agents/core-pages/marketing-home.md`
- فهرست وضعیت پیاده‌سازی: `IMPLEMENTATION_STATUS.md`

## اعتبارسنجی

- ESLint روی `src/components/marketing/homepage-showcase.tsx`
- TypeScript با `npm run typecheck -- --incremental false`
- Build تولیدی Next.js با webpack
- `git diff --check`
- Chrome: بررسی متن و چیدمان سکشن مرجع، و بازبینی دیداری تب حسابداری صفحهٔ اصلی در دسکتاپ. CSS ریسپانسیو را بازبینی کردیم؛ تست دیداری mobile در این تغییر اجرا نشده است.
- Build موفق بود؛ دو هشدار CSS موجود و غیرمانع دربارهٔ `@property --radialprogress` و `@property --aura-angle` باقی ماندند.
